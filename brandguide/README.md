# Brand guide — status and scope

This folder is a **working placeholder**, not SportSG's official brand guideline. There is no publicly downloadable SportSG brand PDF (colors, type spec, logo files, clear-space rules) — only a narrative page about the logo's meaning. If an internal SportSG brand guide becomes available, it should replace this folder rather than be merged with it.

## What's actually public vs. what's derived

| File | Status | Source |
|---|---|---|
| [`logo.md`](./logo.md) | Public narrative, paraphrased | [SportSG — Our Logo](https://www.sportsingapore.gov.sg/about-us/our-logo/) |
| [`colors.md`](./colors.md) | Derived placeholder | Seeded from the [Singapore Government Design System](https://www.designsystem.tech.gov.sg/foundations/colour/brand-colour)'s public red (`#F4333D`), the same value SportSG's own `.gov.sg` site would build on |
| [`typography.md`](./typography.md) | Public spec | [Singapore Government Design System — Typography](https://www.designsystem.tech.gov.sg/foundations/typography) |

## Why it's built this way

SportSG's real brand color is described only as "anchored on red" — no hex code is published. Rather than invent an arbitrary red, this guide seeds its palette from the Singapore Government Design System's own public red, since that's the actual token SportSG's `.gov.sg` site is most likely built on. It's still a guess, not a confirmed match — treat every value in `colors.md` as provisional until checked against the real thing.

**Not included, on purpose:** the actual SportSG logo file. It's a trademarked government asset — reproducing it in this sandbox repo (`sportsafetysandbox`, not an official SportSG-owned account) risks looking like impersonation regardless of intent. See `logo.md` for how to source it properly if this project needs it.

## Before this goes further than a sandbox

If this site is ever going to be presented as SportSG-affiliated (not just a personal prototype), get the real brand guide and logo files from SportSG directly and swap them in here — don't ship the derived palette or a placeholder wordmark as if they were official.
