# Logo

**Source:** [SportSG — Our Logo](https://www.sportsingapore.gov.sg/about-us/our-logo/) (public page, no downloadable asset pack)

## Symbolism, as described publicly

- The mark is an upward spiral "sphere," meant to represent the fullness of life sport brings to people of all ages and abilities.
- The color bands within it stand for diversity — the different ways sport benefits different communities, across boundaries and partnerships.
- The wordmark uses a bold, italicised typeface, described as giving the identity a "confident, future-ready" feel.

This is a paraphrase of the public page's stated intent, not a quote of the design spec — no clear-space, minimum-size, or misuse rules are published.

## No logo file in this repo

The actual SportSG mark is a trademarked government asset. It isn't included here, and shouldn't be scraped from the website or recreated pixel-for-pixel for this project unless SportSG has explicitly provided it for this use.

**If this project needs the real logo:** request it directly from SportSG (their brand/comms team would hold the official files and usage terms), rather than sourcing it informally.

## Placeholder wordmark for prototyping

Until then, the wireframes and mockups in this repo use a plain text wordmark — **SportSG Safety**, sentence case, no italic — so nothing in this sandbox could be mistaken for an official mark. Keep it plain for the same reason if you add more mockups: a convincing-looking placeholder logo is worse than an obviously plain one.
